# Tutorial

Open an existing-mesh model or import .inp, edit supported materials/sections/sets/steps/BCs/loads, and save a new copy. Linux L3 provides selection and undo/redo; keyword viewing is read-only. Configure an external stock ccx and Default/Spooles, require a finished/converged analysis and inspect the .sta/.frd. Gmsh operations explicitly refuse. Windows layup editor/fibre-display source is on windows-rc and develop; those feature sets are not all merged into Linux.
