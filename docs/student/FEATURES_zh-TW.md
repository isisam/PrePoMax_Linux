# PrePoMax-RCM 功能說明

版本：0.1.0-rc1g8-win.1 (RC)　作者：S.Y. Su（保留原始上游作者及授權聲明）

## 能做什麼

- 匯入幾何與網格、設定材料、負載和邊界條件，交給 CalculiX 計算，再看位移與應力等結果。
- 繁體中文介面，可在設定切換英文。
- 疊層複材可看 3D 纖維方向、各層顏色、單層顯示及爆炸圖，方便檢查鋪層角度與順序。
- 已附公開版 stock CalculiX 2.21，預設路徑為 `Solver\ccx.exe`，矩陣求解器預設 Spooles。
- 附彈簧、樑及疊層教學範例。

## 跟原版的差別

沿用 PrePoMax 原有工作流程，增加繁中介面與上述疊層檢視功能。此學生版本改用公開版 stock 求解器；不需要自己解壓縮或手動設定求解器路徑。

## 不能做什麼

這是候選版，主人的 150% DPI 人工檢查尚未完成。疊層畫面用來檢查方向與順序，不能據此證明材料模型正確。 本包不提供私人疲勞與客製材料求解功能。不是商用軟體的完整替代品；支援範圍依 CalculiX 2.21 與模型設定而定。範例只是教學，不能當成工程設計認證。

## 系統需求

Windows 10/11 64 位元、.NET Framework 4.8、支援 OpenGL 的顯示卡與正常驅動。建議至少 8 GB RAM、2 GB 可用磁碟空間；大模型需要更多。 安裝在目前使用者的可寫入資料夾，不需管理員權限。為了讓舊有原生工具正常運作，工作資料夾建議使用簡單英文字母與數字；安裝程式支援空白和中文路徑。

## 怎麼安裝

1. 到 [GitHub Releases](https://github.com/isisam/PrePoMax_Linux/releases) 下載 `PrePoMax-RCM_Setup_0.1.0-rc1g8-win.1.exe`。
2. 雙擊，按「下一步」→「安裝」→「完成」。不需管理員密碼。
3. 預設裝到 `%LOCALAPPDATA%\Programs\PrePoMax-RCM`。
4. 用桌面或開始選單的 PrePoMax-RCM 捷徑開啟；求解器路徑已設定好。

教室批次安裝可用 `PrePoMax-RCM_Setup_0.1.0-rc1g8-win.1.exe /S`。自訂資料夾時，`/D=完整路徑` 必須放最後；不用加引號，例如 `/S /D=C:\Student Apps\PrePoMax-RCM`。

## 怎麼解除安裝

在 Windows「設定 → 應用程式 → 已安裝的應用程式」選擇本程式並解除安裝，或執行安裝資料夾的 `Uninstall.exe`。會移除本包檔案、捷徑與登錄項目。請將自己修改的範例另存到工作資料夾；解除安裝會移除本包附的範例，另存的模型與計算結果會保留。 靜默解除安裝：`Uninstall.exe /S`。

## SmartScreen 顯示未知發行者

本包未以商業憑證簽章，因此可能顯示「未知發行者」。確認檔案來自上述 GitHub release，並比對 SHA256SUMS 後，在 SmartScreen 按「其他資訊」→「仍要執行」。若學校政策不允許，請聯絡學校 IT；不必關閉防毒或安全設定。
