# RC1g 候選版：3D 鋪層方向預覽

2026-10-19，基準 RC1f（d3916d7e），分支 rcm/m2c。

在複材疊層編輯器右側，每層以等角薄板顯示。藍色纖維線表示該層的方向；選取列後，該層及其對稱層改為紅底白線，使用與模型視埠高亮共用的紅色。

角度相對於疊層的局部矩形座標，與求解器使用相同的循環軸定義：

| 疊層軸 | 0° 參考軸 | +90° 軸 |
| --- | --- | --- |
| 1 / X | Y | Z |
| 2 / Y | Z | X |
| 3 / Z | X | Y |

圖上虛線為各薄板的 0° 參考方向。+30° 與 −30° 的纖維線投影方向不同。這是依局部座標顯示的固定等角示意，層間距與板厚不按實際尺寸比例；模型視埠仍用於觀察實際幾何與旋轉。

「對稱」沿用既有展開規則，例如 P01 / P02 會由下而上成為 P01 / P02 / P02 / P01；角度保留原值，不反轉正負號。紅色虛線標出中面。層數較多時可垂直捲動，保留每層的方向線及名稱。最小視窗維持 960 × 760；名稱過長時以省略號顯示，原始名稱保留在表格。

若編輯後的板厚、網格邊界或區域不相容，下方仍會顯示原有驗證錯誤並禁止套用。預覽可以顯示尚未有效的草稿，不能據此判定網格可用。

本次採用的術語為罰函數、幅值曲線、分層、裂紋、載重、疲勞內聚力模型（FATCZM）、邊界框、等值圖、重新產生網格、運動耦合；Step 保留「分析步」。英文、材料名稱、單位、數值與 CalculiX 關鍵字不翻譯。
