# Install

Download the Linux 0.4.0 teaching tarball and SHA256SUMS from [Releases](https://github.com/isisam/PrePoMax_Linux/releases). Verify hashes, extract into a writable directory, install only the documented runtime prerequisites, and run app/run.sh. Configure an external stock CalculiX executable. The research solver and private Gmsh SDK are not bundled. Windows source feature lines are windows-rc/develop; old Windows binary ZIPs are withheld. Native Linux/VM/GPU acceptance remains pending.
