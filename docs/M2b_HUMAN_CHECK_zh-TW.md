# 複材疊層 GUI：8 分鐘人工觀感確認

研究助理：Lota。執行者：project contributor或學生。只判斷旋轉時的外觀、圖表可讀性與中文措辭。
元素 ID、單位換算、驗證、按鈕事件、命令、儲存及重播已有程式證據，不必重做。
請在方便使用桌面時自行執行；本文件不會自動啟動視窗。

## 1. 高亮與旋轉（3 分鐘）

1. 雙擊 `<workspace>\prepomax\run_m2c\PrePoMax.exe`。
2. 點 **File → Open**，開啟
   `<workspace>\prepomax\logs\M2b_acceptance\M2b_layup.pmx`。
3. 點 **Model** 視圖，展開 **Composite Layups**，雙擊 **Persist**。
4. 點表格 **P01** 那一列。將游標移到 3D 模型，**按住滑鼠中鍵／滾輪拖曳**旋轉；
   觀察紅色是否貼著下半層，旋轉前後沒有漂移、殘影或錯染上半層。
5. 點 **P02** 那一列，再以中鍵拖曳；紅色應改到上半層。從側面看內層交界。
6. 勾選：□ 正常　□ 有問題。若有問題，記下角度或截圖。點 **Cancel**。

## 2. 疊層圖閱讀（2 分鐘）

1. 再雙擊 **Persist**。看右側圖，應能直接讀出下方 **P01 30°**、上方 **P02 −30°**。
2. 把視窗縮到允許的最小尺寸，再拉大；只判斷文字、色帶及驗證摘要是否好讀，沒有遮住按鈕。
3. 將兩列 **Thickness** 各改為 `0.25 mm`，每次按 **Tab**；在上方屬性把 **Symmetric** 改為 **Yes**。
   圖應有 P01／P02／P02／P01、清楚的紅色虛線中面。此時驗證顯示錯誤是預期結果。
4. 勾選：□ 圖易讀　□ 須調整（字太小／色帶／虛線／其他：＿＿）。點 **Cancel**，不儲存。

## 3. 中文措辭與材料名稱（3 分鐘）

1. 關閉剛才自行啟動的程式；不要關閉其他人的 PrePoMax 視窗。
2. 雙擊 `<workspace>\prepomax\run_l10n_gui3\PrePoMax.exe`。
   若目前為英文，點 **Tools → Settings**，選左側 **General**，在 **Language** 下拉選單選 **繁體中文**，按確定。
3. 開啟相同 fixture，展開 **複材疊層**，雙擊 **Persist**。
   看左下表格按鈕是否完整寫 **新增**，並讀一遍 **插入、刪除、上移、下移、複製副本、反轉**。
   看 **區域類型、疊層軸、邊界容差** 是否符合實驗室用語。點 **取消**。
4. 如果已有 `USERFATCZM`／`USERFATCZML10N` 材料，展開 **材料**，點它，再點 3D 空白處；
   檢查名稱在選取／失焦後都看得見。如果沒有，不必建立材料；對照
   `logs\M2b_GUI3\l10n_after\main_private.png` 中的 **USERFATCZML10N**。
5. 勾選：□ 用語可接受、文字完整　□ 建議用語／截字：＿＿。
   關閉自己啟動的程式，若詢問儲存模型，選 **否**。

記錄：日期＿＿　執行者＿＿　Windows 縮放＿＿%　畫面問題或建議＿＿。
這三個勾選是人工觀感確認；程式結果不替代project contributor的閱讀與旋轉觀察。
