# 使用教學 / Quick start

先完成[下載與安裝](下載與安裝.md)。材料與幾何一律維持同一單位系統；以下範例使用 N、mm、MPa。材料參數是範例，不代表任意複材的校正值。

## 第一次執行

1. 開啟 release ZIP 的 `Examples/Layup` 範例；先另存新檔到自己的工作資料夾。
2. 檢查 Solver 與 Work directory，使用套件附帶的 Spooles/ccx_fat 設定，執行分析。
3. 確認求解器完成，查看 `.sta` 與 `.dat` 的錯誤／收斂訊息，再開結果。先對照範例 expected.txt，勿將「能開啟模型」視為求解通過。

## 複材疊層

Model tree → Composite Layups → Create。先有符合每一層邊界的 3D solid 網格，指定區域、矩形座標系與 stacking axis，再逐列設定材料、厚度、角度。此功能不會自動分割或擠出網格，也不自動插入 cohesive elements。

列順序由下到上；角度依正層疊軸的右手定則。Global + axis 3 時，0° 為 +X，+90° 為 +Y。「對稱」是選用功能，預設否；`[a,b]` 啟用後成為 `[a,b,b,a]`，中間列會鏡射複製。厚度總和必須等於網格厚度，層邊界須對準元素層（含中間節點）。處理所有 validation 錯誤後再確認及匯出。

RC1g5 可在主 VTK 模型視窗顯示纖維方向，另有選列、尺寸滑桿與透明度預覽；RC1f 不具有這一版的主視窗方向標記。詳見 [COMPOSITE_LAYUP.md](COMPOSITE_LAYUP.md)。[既有 PDF/TeX 教學](tutorial/README.md) 的截圖來自 RC1g2，不能當作 RC1f 或 RC1g5 的逐畫面驗收。

新檔案若含疊層，舊版可能無法開啟。交流前保留原檔；`.inp` 是展開後求解輸入，不是可無損還原疊層編輯的交換檔。

## FATCZM 材料

PrePoMax-RCM 材料編輯器選 Fatigue CZM (FATCZM)，以 Data points 編輯有順序的常數，以 Properties 設 DEPVAR。材料名稱必須以區分大小寫的 `USERFATCZM` 開頭。預設 26 常數與 DEPVAR 6；常數 6 必須是實際 cohesive 層厚度；常數 14 是第一個疲勞步；啟用起裂時鐘須 DEPVAR 至少 8。先準備 cohesive 薄層元素與邊界條件，再使用材料，不能只對一般實體亂套參數。

確認常數的單位與次序，再檢查匯出的 `*USER MATERIAL`、`*DEPVAR`、步設定。v1.2 的第 30 常數是獨立候選功能，不是 RC1f 26 常數 preset 的新預設。省略或 0 保留舊切線；1 才啟用新切線。自動縮步是另一個輸入設定，不能把疲勞時間直接當作物理循環數。

## English

Run an unchanged release example in a separate work folder first. Check solver exit, convergence and expected values before editing. Composite layups assign materials/orientations to an existing conforming solid mesh; they do not remesh or insert cohesive layers. Rows are bottom-to-top and angles use the right-hand rule. Symmetry is optional and mirrors the entire supplied sequence. FATCZM requires the case-sensitive USERFATCZM prefix, correctly ordered constants, consistent units, actual layer thickness and sufficient DEPVAR. See the English material definition and the retained tutorial's version warning.
