# 使用教學

先開啟已有網格的模型或匯入 .inp。設定材料、section、sets／surfaces 及支援的 step／BC／load；存成新檔。主分支的 Linux checkpoint 支援選取與 undo／redo，關鍵字檢視為唯讀。將 analysis 的 solver 指向外部 stock ccx，使用 Default／Spooles；檢查求解完成與 .sta／.frd 後再查看結果。Gmsh meshing 尚為拒絕 stub。Windows 的疊層編輯與 3D 纖維顯示請見 windows-rc／develop 分支；docs/tutorial 的舊教學畫面不等於 Linux 全部功能已完成。
