# 下載與安裝

到 [Releases](https://github.com/isisam/PrePoMax_Linux/releases) 下載 Linux 0.4.0 teaching tar.gz 與 SHA256SUMS，以 `sha256sum -c SHA256SUMS` 核對，再解壓到可寫入目錄。依包內 RUNTIME_PACKAGES.md 安裝 Ubuntu／Debian runtime 相依（WSL apt 可用）；已有相依時不需重裝。執行 `app/run.sh`。選用外部 stock CalculiX；本包不附研究求解器。Windows 學生採 windows-rc 原始碼與 [CalculiX_Win](https://github.com/isisam/CalculiX_Win/releases)；本倉庫不提供含私人 gmsh 的舊 Windows ZIP。原生 Linux／VM／GPU 驗收仍待完成。
