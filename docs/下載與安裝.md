# 下載與安裝（繁體中文優先）

1. 登入獲授權的 GitHub 帳號，打開本倉庫的 **Releases**。私人倉庫須先受邀，不能匿名下載。選穩定版；展開 Assets，下載 Windows ZIP 與同一版 `SHA256SUMS`。GitHub 自動產生的 Source code ZIP 是原始碼，不能直接執行。
2. 在 PowerShell 對下載的 ZIP 核對雜湊，逐字比對 SHA256SUMS 中同名檔案的 64 位數值：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\下載的檔案.zip'
```

雜湊不符時重新下載；不要執行該檔。檔名與大小不能代替 SHA-256。

3. 使用 Windows「全部解壓縮」，建議放在自己可寫入的短英文目錄，例如 `D:\Apps`，不要直接在 ZIP 內執行。每個版本使用不同資料夾。
4. 建立工作資料夾，例如 `D:\FEMWork\case01`。將範例複製進去再修改；保留原始輸入與求解結果分開。工作資料夾不得和程式目錄混在一起。

5. 以解壓後的 `PrePoMax.exe` 開啟。RC1f（`v0.1.0-rc1f`）為已交付學生的穩定版；RC1g5（`v0.1.0-rc1g5`）是預發行：**150% DPI manual check pending**。
6. 首次啟動時，zh-TW Windows 預設繁中，其他系統預設英文。在 Settings 中選擇介面語言；介面文字不同可對照隨附英文 QuickStart。請使用套件附帶的求解器，不要另以一般 ccx 取代 FATCZM 求解器。
7. Settings 的 solver work directory 預設為 `%USERPROFILE%\Documents\PrePoMax-RCM\Work`。可改為自己的工作目錄；已有設定的舊版升級不會強制覆寫自訂路徑。啟用「Use .pmx folder as work directory」前先儲存模型。
8. 程式需要完整 ZIP 中的相依檔，不能只複製 EXE。遇 Windows 封鎖或權限問題，先確認下載來源與雜湊，再依學校電腦管理政策處理；不需要為一般使用改成系統管理員。

## English

Open this repository's Releases with an authorized GitHub account. Download the release ZIP and matching SHA256SUMS, not the automatic source archive. Verify with `Get-FileHash -Algorithm SHA256 -LiteralPath 'file.zip'`, or `shasum -a 256 file.zip` on macOS / `sha256sum file.zip` on Linux. Extract the complete archive to a writable folder and create a separate work directory. Keep versions separate. Follow the Chinese steps above and [usage](使用教學.md); parameter definitions are also supplied in English. Private access is required until the repository is made public.
