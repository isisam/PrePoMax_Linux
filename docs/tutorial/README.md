`main.pdf`（23 頁）、`main.tex`、`figs/` 與兩份最小 `.inp` 重用已交付的 v2 3D 教學。原始教學署名與圖文保留；輸出 `.dat/.frd`、私有 evidence 清單與來源路徑報告未納入；TeX 需要的三份 evidence/*.inp 程式片段保留。PDF/TeX/圖片的 bytes 與交付來源相同。

English: this is the previously delivered RC1g2-era, ccx_fat v1.1b tutorial.
