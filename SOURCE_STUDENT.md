# Student Windows candidate source

Author: S.Y. Su. Original upstream credits and licences are retained.

Baseline: RC1g8 source snapshot 4a6c571cca162ffba429254c5e3f888cbedd8744 from the supplied candidate source bundle.
This clean tree contains the student variant only. It retains RC1g8 composite views and replaces the custom solver integration with stock CalculiX 2.21. The default UI is zh-TW and the default solver is Solver/ccx.exe (Spooles). The default work folder is the application's Work subfolder.

Rebuilt assemblies: CaeModel.dll, APIs.dll, PrePoMax.Core.dll and PrePoMax.exe. Other runtime dependencies are byte-preserved from the RC1g8 candidate and have their original corresponding-source notices in Licenses.

Rebuild the managed changes on Windows with .NET SDK 8.0.426 and Microsoft.NETFramework.ReferenceAssemblies.net48 1.0.3. The packaging/student/Rebuild-Managed.ps1 recipe invokes Roslyn directly with net48 references, release optimisation, deterministic output, no PDB, and a public R:\src path map. It copies compiled embedded resources from the supplied runtime. To repeat: set BuildRoot to a task folder containing this tree as rc1g8, an extracted student installation as runtime, the SDK under dotnet, and the reference assembly package under net48. Run the recipe, then take the four assemblies from managed. The four rebuilt assemblies must be copied after PowerShell exits because resource extraction holds read handles.

An installed student runtime is sufficient as the reference runtime: it carries the same embedded resources and unchanged public dependencies. No earlier custom-solver binary is needed. To build all projects from scratch, use VS 2022 Build Tools with C++ and .NET Framework 4.8 developer tools, restore NuGet packages and follow build/Build-Windows.ps1.

NSIS scripts in packaging/student are generated by make_nsis.py. Arrange sibling payload and dist folders as shown by File and OutFile paths, then run makensis. Native runtime assembly uses the selected-runtime manifest; no source-history bundle is shipped in the installer.

The solver is stock CalculiX 2.21 with the Windows SPOOLES I2Ohash 64-bit multiplication fix. CalculiX-2.21-SPOOLES-win64.3-source.zip is supplied as a separate release asset, with dependency sources and relinkable objects. Third-party modified native components retain their precise published source locations in Licenses/README.md.

This is RC software. The owner's manual 150% DPI inspection remains pending.

Generated bytecode caches are excluded from installers. Embedded CPython may create them while running; uninstall removes only *.pyc files inside __pycache__ subdirectories of the shipped Python directories, then removes empty directories. It retains user-created source and result files. Environment-only suppression was not effective for this embedded runtime and is not used.

To rebuild the NSIS installer directly, copy packaging/student to a new workspace as packaging, create sibling payload and dist folders, and copy the extracted student installation into payload/PrePoMax-RCM. Run makensis from packaging on PrePoMax-RCM.nsi. The generated NSIS manifest is ready to compile; regenerating it is optional. For regeneration, also supply the bilingual docs and screenshot directories expected by make_nsis.py. Staging-only scripts and their local filesystem locations are intentionally omitted from this public source snapshot.

Update v0.1.0-rc1g8-win.2: managed application binaries and all other runtime dependencies remain byte-identical to win.1. Only Solver/ccx.exe, installer version and documentation change. ccx_dynamic 2.22 is not rebuilt or replaced; it was not part of the previous student Setup. For this patch package use the checked-in NSIS scripts with the verified win.1 payload, replacing only Solver/ccx.exe and the release documentation. Historical payload regeneration scripts describe win.1; do not run them to regenerate this patch.
