# Stock upstream verification inputs

Unmodified beamp.inp (static beam with section forces), beamf.inp (ten ARPACK modes), spring1.inp (linear spring; displacement F/k = 0.1).
Source: https://www.dhondt.de/ccx_2.21.test.tar.bz2 , SHA256 094a0a2ec324fc6f937a96e932b488f48f31ad8d5d1186cd14437e6dc3e599ea.
These are upstream CalculiX tests, covered by the original CalculiX notices. Numerical references are produced by Ubuntu CalculiX 2.21-1 and recorded with hashes. Run `python scripts/verify_stock.py --exe /path/ccx.exe --work /new/work`.
