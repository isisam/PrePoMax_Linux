# 回報問題 / Reporting issues

在本倉庫 Issues 建立問題，附版本/tag、下載資產 SHA-256、Windows/macOS/Linux 版本及架構、重現步驟、預期與實際行為。UI 問題附顯示比例與經匿名化截圖；求解問題附最小 .inp 與必要的錯誤片段、exit code、執行緒設定。

先移除個人姓名、帳號、絕對路徑、未公開研究資料與憑證。不要直接上傳含完整私人歷史的 .pmx/.pmh；另建最小案例。未公開研究問題先由課程管理者確認可分享範圍。

English: open an Issue with version, asset SHA-256, OS/architecture, reproduction steps, expected/actual behavior and a minimal anonymized input. Include display scaling for UI bugs and exit/error details for solver bugs. Exclude private project history, personal paths, credentials and unpublished data. Source changes should include a focused description and relevant regression evidence.
