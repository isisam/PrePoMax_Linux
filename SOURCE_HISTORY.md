# Source history and publication boundary

This repository retains the upstream commit sequence, authorship, timestamps, merge topology and our subsequent feature commits. Original upstream tip: 912fb3d08014f246d48bef14d62a2cba0fdf5bb0. Original feature references: rcm/l3b2 (Linux L3 0.4.0), d3916d7eaeebad8079f1c8c12dd5b60f6ffc26f9 (RC1f), a6a29eb2f5ece2ba83b5f2f38ffa574e04fbf874 (RC1g5).

The earlier private preparation preserved upstream hashes. For this public repository, the vendored Gmsh SDK (all headers, binaries, wrappers and examples), ThirdParty/QuadMesher and a legacy upstream mmg3d binary containing a private build path were omitted from every historical tree. Affected upstream commit hashes therefore change. This is a content-filtered history, not byte-identical upstream commits. Original staging and audit maps are retained privately by the owner; do not push their refs or objects.

The L3b2 branch inherits the earlier net8 Gmsh refusal stub, not the later L1g native interop work. Public PrePoMax integration source is retained; no unpublished Gmsh implementation is included. Private paths and our contributor metadata were already generalized during the preceding source preparation. License/copyright attribution is retained.
